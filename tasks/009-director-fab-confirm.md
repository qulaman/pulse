## Шаги
1. `lib/voice/api.ts` — типизированный клиент к четырём роутам (fetch с `credentials: 'include'`, JSON, маппинг `{error:{code}}` в `class VoiceApiError { code, status, body }`).
2. `lib/voice/recorder.ts` — `createRecorder()`: `getUserMedia({ audio: { noiseSuppression: false, echoCancellation: false, autoGainControl: false } })` (сырой звук — итог гейта), `MediaRecorder` с первым поддерживаемым mimeType из матрицы `audio/mp4` → `audio/webm;codecs=opus` → `audio/webm`, `audioBitsPerSecond: 48_000` (best-effort); `start()`, `stop(): Promise<{ blob, mime, durationMs }>`, `cancel()`; уровень громкости через `AnalyserNode` (`onLevel(cb)`, 0..1, для пульсации кнопки); поток микрофона закрывается после stop/cancel. Расширение для upload-url: mp4 → `m4a`, webm → `webm`.
3. `lib/store/ingest.ts` (zustand) — машина состояний `idle → recording → uploading → transcribing → parsing → confirm → sending → done`, плюс `error` с полем `code` (коды AI.md §11 + `network`) и `retryFrom` (`upload`|`transcribe`|`parse`|`send`); хранит `client_request_id` (генерируется в момент начала записи/ввода текста и не меняется до `done`/сброса), `audio` (blob+mime+durationMs), `audio_path`, `inbox_id`, `transcript`, `source`, `entities: PostprocessedEntity[]` (редактируемая копия) и `parsed_entities` (исходник для diff), `suspicious`. Действия: `startVoice()`, `stopVoice()` (→ upload → transcribe → parse), `cancelVoice()`, `submitText(text)` (→ parse с `source:'typed'`), `retry()`, `editEntity(i, patch)`, `removeEntity(i)`, `send(force_now?)`, `reset()`. Запись короче 1000 мс → `error: record_too_short` без сетевых вызовов. Тест `lib/store/ingest.test.ts` с замоканным `api`: (а) текстовый путь до `confirm`; (б) `empty_transcript` → error с кодом; (в) `stt_failed` → `retryFrom='transcribe'` и `audio_path` сохранён; (г) `send` собирает payload: служебные поля `assignee`/`blocked` вырезаны, `assignee_id` = выбранный кандидат.
4. `components/voice/VoiceButton.tsx` — FAB по техконтракту FRONTEND: Pointer Events + `setPointerCapture`, `touch-action:none`, `-webkit-user-select:none`, `-webkit-touch-callout:none`, `contextmenu → preventDefault`; удержание ≥250 мс → запись (кольцо вокруг кнопки масштабируется по уровню громкости — только `transform`), отпускание → `stopVoice()`; тап <250 мс → шторка текстового ввода (`components/voice/TextSheet.tsx`: поле + «Отправить», без чипов пресетов в этом наряде); свайп вверх ≥60px во время удержания → `cancelVoice()` с подсказкой «Отпусти, чтобы отменить». Цвет `--accent`, размер 64px, тень по DESIGN. Хаптик — `navigator.vibrate?.(20)` на старте записи (обёртку `lib/haptics.ts` создать: `haptic(pattern)` no-op вне Android/без API).
5. Прогресс между состояниями — `components/voice/IngestOverlay.tsx`: полноэкранная подложка `--overlay` с одной строкой в tone of voice: «Слушаю…» (recording, с таймером мм:сс), «Сохраняю…», «Распознаю…», «Разбираю…» + скелетон трёх карточек; ошибки — карточка с текстом из §11 и кнопками: `record_too_short` → тост «Слишком коротко»; `empty_transcript` → «Не понял, повторить?» [Повторить]; `stt_failed` → «Не расслышал. Аудио сохранил — повторить?» [Повторить]; `parse_failed` → «Распознал текст, но не разобрал» + транскрипт [Повторить]; `parse_refused`/`parse_empty` → транскрипт + [Создать задачу вручную] (кнопка ведёт в /confirm с одной пустой task-сущностью с `title = transcript`); `network` → «Нет связи. Попробую ещё раз» [Повторить]. Переход в `confirm` → `router.push('/confirm')`.
6. `app/(director)/confirm/page.tsx` + `components/confirm/*`: заголовок «Понял так: {N задач и M объявлений}» (склонение: 1 задача/2 задачи/5 задач); список `EntityCard` по `kind`: ✅ task (title, чип исполнителя, чип дедлайна, чип приоритета при `high`), 📢 announcement (text), 🔔 reminder (text + время), 🔁 recurrence (title + читаемый rrule как есть), 🧩 delegation (как task), ❓ query (серый чип «вопрос → ассистенту, не в задачи», исключён из отправки), ➕ points (карточка приглушена, чип «Очки включатся после пилота», исключена из отправки). Чипы: исполнитель — `matched` + `flag:'ok'` → нейтральный; `flag:'check'` → `--warn` «проверь»; `ambiguous` → `--warn` «Кто?» тап → `AssigneePicker` (шторка с кандидатами, затем «Все сотрудники»); `unmatched` → `--danger` «Кому?» тап → полный список (ростер через TanStack `useQuery(['roster'])` из `profiles` под RLS); дедлайн — «до 14.08 13:00 · „завтра до обеда“» (`deadline_source_text`), при `deadline_confidence < 0.8` — `--warn`; `null` → серый «без срока»; тап → `DeadlineSheet` с пресетами «Сегодня 18:00», «Завтра 9:00», «Завтра 13:00», «Без срока» и `<input type="datetime-local">`. Тап по заголовку → инлайн-редактирование title (`contentEditable`-free: `<input>` на месте текста, Enter/blur сохраняет). Кнопка × в углу карточки — удалить. При ≥5 сущностей — компактный режим: однострочные карточки, тап разворачивает.
7. Нижняя sticky-панель: «Отправить N из M» (N = сущности без `blocked`, не query/points; M = все, кроме query/points) — disabled при N=0; если сейчас вне окна 08:00–21:00 Asia/Aqtobe (клиентская проверка по `Date`, окно захардкожено здесь; серверная — в RPC) — под кнопкой пометка «Отправлю утром в 08:00» и ссылка «отправить сейчас» (→ `force_now: true`). После успешного `send` — тост «Отправил {имена через запятую}» (имена из выбранных исполнителей; объявления — «и объявление в Эфир»), `reset()`, `router.replace('/pulse')`. `duplicate: true` — тот же успех. Кнопка «🎤 переговорить эту сущность» — НЕ в этом наряде (записать в отчёт как отложенное).
8. `app/dev/confirm/page.tsx` — песочница: кнопка «Загрузить фикстуру» кладёт в стор 5 сущностей (task matched, task ambiguous — два Ерлана, task unmatched, announcement, points) и открывает тот же `ConfirmScreen` без сети; кнопка «Ошибка: stt_failed» показывает `IngestOverlay` в состоянии ошибки. Отправка из песочницы — заглушена (тост «песочница»).
9. Подключить `<VoiceButton>` и `<IngestOverlay>` в `app/(director)/layout.tsx` (на всех экранах директора, кроме `/confirm`, где FAB скрыт).
