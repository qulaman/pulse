## Что это такое (концепция, зафиксирована D-153)

Отдельный интерфейс по адресу `/desk/*` в том же деплое и с той же авторизацией. Пускает только `ADMIN_ROLES` (директор, секретарь; `canManageTeam` в `lib/routes.ts`). На десктопном браузере директор и секретарь после входа попадают сюда сами; с телефонных адресов их переводит сюда `proxy.ts`; обратно — переключатель «Телефонная версия».

Чего здесь нет намеренно: Пульса, маскота, шариков, жестов, свайпов, колоды, нижних шторок как шторок, пристыкованных к низу окна панелей. Что есть вместо: боковая навигация, таблицы с сортировкой и фильтрами, панель справа (мастер-деталь), диалоги по центру, клавиатура. Обратная связь тихая: подсветка строки, в которую пришло изменение по Realtime, тост «принято», живые счётчики. Game feel принципа 1a на десктопе читается так: действие мгновенно, подтверждение видно, маскота нет.

Главный экран директора — «Задачи» (набросок; ширина 1440):

### Вход по устройству (`lib/desk/device.ts`, `proxy.ts`)

- `isDesktopUa(ua, chMobile)`: заголовок `sec-ch-ua-mobile` = `?0` → десктоп, `?1` → телефон; без заголовка — десктоп, если UA не содержит `/Mobi|Android|iPhone|iPad|iPod/i`. Unit-тест.
- Cookie `pulse_view=phone` (год, `SameSite=Lax`) выключает перевод на десктоп; ставит «Телефонная версия» в `/desk/profile` (и тут же уводит на `homeForRole`); снимает строка «Версия для компьютера» в телефонном профиле директора и секретаря (уводит на `/desk`). Без cookie — по UA.
- `deskRouteFor(pathname, search, role): string | null` (`lib/desk/routes.ts`, unit-тест) — телефонный адрес → десктопный, только для адресов, у которых есть десктопный экран для этой роли: `/pulse`, `/sent`, `/confirm` → `/desk/tasks`; `/tasks/<id>` → `/desk/tasks?id=<id>` (директор; секретарю — `null`, её задача открывается на телефонном экране); `/people` → `/desk/team`; `/people/new` → `/desk/team/new`; `/people/<id>` → `/desk/team/<id>`; `/people/<id>/edit` → `/desk/team/<id>?edit=1`; `/settings` → `/desk/settings` (с `?tab`); `/settings/dictionary` → `/desk/settings/dictionary` (с `?tab`); `/lab` → `/desk/settings/lab` (с `?tab`; подстраницы `/lab/*` — `null`); `/admin` → `/desk/settings/data`; `/secretary` → `/desk/errands` (с `?e`); `/calendar` → `/desk/calendar`; `/notes` → `/desk/notes` (с `?tab`); `/notes/b/<id>` → `/desk/notes/b/<id>`; `/screen` → `/desk/screen`; `/reports` → `/desk/reports`; `/rating`, `/shop` → `/desk/settings/points` (директор); `/feed` → `/desk/errands` (секретарь); `/profile` → `/desk/profile`. Остальное — `null`.
- `proxy.ts`: для вошедшего пользователя на десктопном UA без `pulse_view=phone`, если `deskRouteFor` для пути потенциально не `null`, — один запрос роли (`profiles.role`, как уже делается для `/`), и если роль в `ADMIN_ROLES` — redirect на десктопный адрес (cookies сессии сохраняются, как в `redirectTo`). На телефонном UA ничего не меняется: ни одного лишнего запроса. На `/` и экранах входа с десктопного UA домой ведёт `deskHomeFor(role)`, а не `homeForRole` — один переход вместо двух. `/desk/*` в `isPublicPath` не входит: без сессии — `/login`, как всё.
- Пуш, открытый на десктопе (`info.url` в `public/sw.js`, адрес телефонный), доезжает до десктопного экрана этим же переводом; `sw.js` не трогать.

### Оболочка (`app/desk/layout.tsx`, `components/desk/DeskShell.tsx`)

- `app/desk/layout.tsx` (server): `getSessionProfile()`; `AuthError` → `/login`; не `canManageTeam` → `redirect(homeForRole)`. Читает `loadBrand()` (логотип, акцент, `pointsEnabled`) и `tabScope(profile)` — всё, как в `app/(employee)/layout.tsx`. Рендерит `<DeskShell me role brand>{children}</DeskShell>`; `metadata.title` — «Pulse». Вложенные `page.tsx` — клиентские, данные — TanStack Query через хуки `lib/**`; `RoleScope` из телефона НЕ используется (там контекст таб-бара); вместо него `DeskScope` (ниже) сеет `me` в кэш тем же способом (`queryClient.setQueryData(taskKeys.me(), me)` в `useState`-инициализаторе, см. `components/RoleScope.tsx`) и зовёт тот же `NamesSync`-эквивалент (`setCompanyNames` по `useRoster`).
- `DeskShell` (client): CSS-grid `grid-cols-[232px_minmax(0,1fr)]`, высота `100dvh`, прокручивается только `<main>`. Слева `SideNav`: логотип клиента (как `AppHeader`), пункты по роли с бейджами (см. таблицу), внизу «Профиль». Сверху в `<main>` — `TopBar`: у директора `CommandLine` на всю ширину, справа у обоих имя · роль · «Телефонная версия». Справа — слот панели `DeskPanel` (ширина 440 px, своя прокрутка, кнопка × и Esc), управляется контекстом `useDeskPanel()` → `{ open(node, { key }), close(), isOpen }`; панель — часть грида (`grid-cols-[232px_minmax(0,1fr)_440px]` пока открыта), не оверлей.
- На `<html>` при монтировании оболочки — `data-surface="desk"` (эффект; снять при размонтировании). Под `html[data-surface="desk"]` в `globals.css`: `--tabbar-space: 0px; --dock-space: 0px`; `.above-tabbar { position: static; translate: none }`; **`Sheet` становится диалогом по центру**: тот же компонент `components/ui/Sheet.tsx`, но слой — `display: grid; place-items: center`, карточка `max-width: 560px; border-radius: 16px`, появление — fade + scale 0,98→1 за 160 мс вместо выезда снизу (`prefers-reduced-motion` — без движения), `--kb` не учитывается. Код `Sheet.tsx` менять можно только там, где CSS не хватает (например, конец анимации ждёт другого `animationend`); телефонный путь не меняется — это проверяет смоук на 390×844. Так все телефонные шторки (события, срок, люди, выход с устройств, «Что мешает?») работают внутри десктопа без переписывания.
- Бейджи навигации — из тех же хуков, что у `TabBar`: «Задачи» — `inboxCounts(useDirectorInbox(me))` суммой; «Заявки» — `activeCount(useErrands())` + «ждут директора» из `awaitingDirector(useVisits())`; «Календарь» — `todayCount` из `lib/calendar/agenda.ts`; «Отчёты» — не сдавших сегодня нет в дешёвом хуке → без бейджа. Прогрев: при входе `warmSentTasks`, `warmCalendarMonth(monthOf(now))`, `warmNotes` — как делает `TabBar`.
- Ширина меньше 960 px: оболочка показывает поверх контента узкую плашку «Этот экран удобнее на телефоне · Открыть телефонную версию» (ставит `pulse_view=phone`), контент не прячет.
- Клавиатура (везде в `/desk`): `Ctrl/Cmd+K` или `/` вне поля — фокус в строку поручения; `Esc` — закрыть панель/диалог/снять фокус. Коды клавиш — `event.code` (`KeyA`, `KeyR`, `KeyO`, `Enter`, `ArrowUp/Down/Left/Right`), чтобы русская раскладка работала.
