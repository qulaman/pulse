# План на 12 недель — WAG Pulse: от нуля до работающей системы в WAG

Цель 12 недель: продукт ежедневно используется всей компанией WAG, директор проводит через него все поручения, есть метрики для инвестора и материал для первого внешнего демо.

---

## Ежедневный ритм (пн–сб)

| Время | Что |
|---|---|
| 05:00–07:00 | Подъём, своё время: мысли, чтение, планирование дня (3 приоритета, не больше) |
| 07:00–09:00 | Завтрак, разбор мелочей (сообщения, быт) — НЕ код |
| 09:00–10:30 | Тренировка (чередование: силовая / плавание) |
| 10:30–13:30 | **Глубокая работа, блок 1** — самое сложное задачи дня, телефон в другой комнате |
| 13:30–14:30 | Обед + сон 60 мин (будильник обязателен, дольше — разбитость) |
| 14:30–18:00 | **Глубокая работа, блок 2** — Claude Code сессии, тесты, деплой |
| 18:00–21:30 | Ужин, семья/личное, прогулка. Никакого кода после 18:00 — правило |
| 21:30–22:00 | Отбой к 22:00 |

Реальная ёмкость: ~6–6.5 часов глубокой работы в день × 6 дней = 36–39 часов в неделю чистой разработки. Это много при работе с Claude Code, но план ниже свёрстан под эту ёмкость — не под фантазийные 12 часов.

**Недельный ритм:**
- **Пятница 16:00** — демо директору, 30 минут, что-то работающее КАЖДУЮ неделю. Это дисциплинирует сборку и держит инвестора вовлечённым.
- **Суббота** — лёгкий день: фиксы, документация, планирование следующей недели.
- **Воскресенье** — полный выходной. Не обсуждается. Марафон на 12 недель выигрывает отдохнувший.

## Два параллельных трека

**Трек Р (разработка)** — основной, 80% времени.
**Трек Б (бизнес/оформление)** — ТОО, Astana Hub, транши, договорённости. Делается в окне 07:00–09:00 и в перерывах, НЕ из блоков глубокой работы.

## Недели 1–4: MVP

### Неделя 1 — фундамент + главный гейт
- **Гейт СТТ (день 1–2):** записать 30 реальных фраз директора (имена, смешанная речь, шум) → прогнать через Whisper → если точность имён <95%, тестировать Deepgram/gpt-4o-transcribe ДО написания UI. Это решение определяет весь стек.
- Репозиторий, CLAUDE.md и доки внутрь, Supabase проект, Vercel.
- Миграции ядра: companies, profiles, tasks, task_messages + RLS + негативный тест «сотрудник не видит чужие задачи».
- Auth + роли, справочник сотрудников с алиасами (заполнить реальными людьми WAG).
- Б: финализация условий с инвестором (доли! см. риск 50/50), старт оформления ТОО.
- ✅ Критерий недели: СТТ-гейт пройден, схема ядра в проде, логин работает.

### Неделя 2 — личный канал и доставка
- Лента диалога (feed): карточка задачи, 3 кнопки, композер (текст/фото/голосовое).
- «Мои дела», статусная машина задач.
- Web Push (VAPID) + Telegram-fallback бот + индикатор недоставки у директора.
- ✅ Критерий: задача, созданная вручную в БД, доходит до телефона сотрудника пушем, он принимает, статус виден.

### Неделя 3 — голосовой конвейер
- /api/voice/transcribe (аудио в Storage до AI-вызовов), /parse (промпт + few-shot + телеграфный стиль), matchName с алиасами.
- Двухрежимная FAB (зажал — голос, тап — текст), экран подтверждения с чипами-правками.
- ai_logs с первого дня.
- ✅ Критерий: сказал фразу → карточка на подтверждении → «Всё верно» → у сотрудника пуш. < 3 сек на распознавание.

### Неделя 4 — Пульс + приёмка
- Пульс блоки 1–3 (вердикт, «Требует вас», живая лента Realtime), mv_pulse_summary.
- Приёмка задач (пока кнопками, свайпы позже), pending_review → done/rework.
- Блок «Люди» с точками загрузки.
- Б: документы в ТОО поданы; подготовка заявки Astana Hub.
- ✅ Критерий: **MVP готов.** Полный цикл голос → задача → отчёт → приёмка работает end-to-end.

## Недели 5–6: пилот на живых людях

### Неделя 5 — пилот: директор + 5 лояльных сотрудников
- Онбординг лично каждого (PWA на главный экран, push, первая задача).
- Договорённость с директором: ВСЕ поручения этим 5 людям — только через систему, 30 дней.
- Ты — живая поддержка: реагируешь на любую проблему в тот же день.
- Ежедневно читать ai_logs: что директор говорит, что парсер понял, что правилось.
- ✅ Метрика недели: % поручений через систему (цель >80%), доля правок на подтверждении (высокая = дорабатывать промпт).

### Неделя 6 — фиксы по пилоту + Эфир
- Правки по реальному фидбеку (их будет много — это нормально, для этого неделя).
- Эфир: объявления с аудио, «принял к сведению», мульти-сущности из одного голосового.
- Тихий режим + быстрые ответы-чипы.
- Б: заявка в Astana Hub подана.
- ✅ Критерий: утреннее голосовое директора разлетается на объявление + N задач одним подтверждением.

## Недели 7–9: ассистент, геймификация, вся компания

### Неделя 7 — ИИ-ассистент директора
- Vercel AI SDK: streamText + tools (search_tasks, employee_tasks, who_not_reported, overdue_list, summary_today) + useChat.
- Вопросы голосом и текстом: «что там по Казхрому?», «кто не отчитался?».
- ✅ Критерий: директор задал 5 разных вопросов — получил верные ответы с карточками. Это демо-момент №2, показать в пятницу обязательно.

### Неделя 8 — очки, реакции, game feel
- point_transactions, авто-правила, ручные начисления (тапом и голосом), реакции с золотой обводкой.
- Рейтинг в Эфире, профиль с балансом и streak.
- EffectsLayer + первые эффекты: стрела отправки, частицы очков, вонзание карточки.
- ✅ Критерий: начисление голосом «Ерлану плюс десять» работает; стрела летит; на Redmi-классе нет лагов.

### Неделя 9 — раскатка на всю компанию (~45 человек)
- Онбординг волнами по отделам (не всех в один день), памятка + помощь на местах.
- Свайп-приёмка (нагрузка на директора вырастет — теперь она нужна).
- Согласия на обработку ПД и публичный рейтинг (закон РК) — собрать при онбординге.
- ✅ Метрика: >70% сотрудников приняли хотя бы одну задачу за неделю; push-доставляемость по устройствам (найти проблемные Xiaomi/Huawei — перевести на Telegram).

## Правила выживания плана

1. **Скоуп-дисциплина.** Новые идеи (свои и директора) — в бэклог, не в текущую неделю. Пересмотр бэклога — по субботам. Фильтр прежний: добавляет тап к основному флоу — не берём.
2. **Пятничное демо неприкосновенно.** Не готово идеальное — показывай что есть. Неделя без демо = первый звонок, две подряд = план пересматривается.
3. **Если неделя поплыла** — режем скоуп недели, не сон и не тренировки. График 5:00–22:00 и есть твоё главное преимущество перед командами; сломаешь его — сломаешь 12 недель.
4. **Буфер честности:** недели 6 и 12 наполовину буферные. Если всё идёт по плану — отлично, опережай. Если нет — они спасают график без паники.
5. **Б-трек не крадёт кодовое время.** Бюрократия ТОО/Hub — утренние окна и обеденные паузы. Один день полностью на бюрократию допустим раз в 2–3 недели.
