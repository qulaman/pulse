# DESIGN.md — дизайн-система Pulse

Что это: контракт визуального языка продукта Pulse — палитра, токены, типографика, движение, маскот, tone of voice; для агентов, реализующих UI, и как основа брендинга SaaS (D-44). Арбитр — `DECISIONS.md`. Поведенческие спеки экранов — `docs/FRONTEND.md` (этот док задаёт «как выглядит и звучит», тот — «как работает»).

## 1. Принципы

1. **Айдентика продукта первична (D-44).** Всё ниже — бренд Pulse, одинаковый на всех инстансах. Клиентская кастомизация строго ограничена: логотип клиента в шапке + опциональная замена акцента (`company.settings.brand`), больше ничего. Тексты UI не упоминают клиента вне конфига.
2. **Тёмная тема — основная и единственная в v1.** Дорогой, спокойный вид; статусные цвета горят на тёмном.
3. **Цветовая дисциплина.** Один акцент бренда; green/yellow/red — ТОЛЬКО для статусов задач и точек загрузки; золото — ТОЛЬКО для реакций директора и подсветки нового на ТВ; всё остальное — нейтрали. Никакого цветного шума.
4. **Крупная типографика.** Ключевые числа Пульса читаются на вытянутой руке; кегль тела ≥16px.
5. **Движение = информация.** Анимация объясняет, что произошло (улетело, пришло, начислилось), а не украшает. Правила бюджета — FRONTEND.md; здесь — длительности и кривые.
6. **Ничего не дёргается.** Скелетоны вместо спиннеров, стабильные размеры, optimistic UI. Полировка тратится сначала на отсутствие джанка, потом на спецэффекты.

## 2. Токены

Единый источник — `lib/design/tokens.ts` (+ CSS-переменные в корне). Значения ниже — рабочий стандарт; финальный hex акцента утверждается пакетом с именем продукта (D-20) после визуальной пробы.

### Цвет

| Токен | Значение | Использование |
|---|---|---|
| `--bg` | `#0B0F14` | фон приложения |
| `--surface` | `#131A22` | карточки, шторки |
| `--surface-2` | `#1B242F` | приподнятые элементы, поля ввода |
| `--border` | `#243040` | разделители, обводки (1px) |
| `--text` | `#E8EEF4` | основной текст |
| `--text-muted` | `#8C99A8` | вторичный текст, подписи |
| `--accent` | `#2ED3B7` | бренд Pulse («пульс-циан», линия кардиомонитора): FAB, ссылки, активные состояния, спокойный маскот |
| `--gold` | `#F0B24A` | только реакции директора, подсветка нового на ТВ, «доволен» у маскота |
| `--ok` | `#34C759` | статус «в срок», успех |
| `--warn` | `#FFB020` | «дедлайн близко», жёлтые чипы confidence, «ждёт» |
| `--danger` | `#FF5A52` | просрочка, ошибки, «недоволен» (приватно) |
| `--overlay` | `rgba(4,8,12,.6)` | подложки шторок |

Правила: `--accent` и `--gold` не смешивать в одном элементе; `--danger` никогда не анимировать «весело»; замена акцента клиентом (`company.settings.brand.accent`) допустима, если контраст с `--bg` ≥ 4.5:1 — иначе UI игнорирует настройку и остаётся дефолт.

### Типографика

Два шрифта, оба self-hosted через `next/font` (никаких запросов в рантайме, оффлайн работает, D-50): **Manrope** — заголовки, кнопки, чипы, таб-бар и все числа (`--font-display`, трекинг −0.02em у h1/h2), **Golos Text** — основной текст, родная кириллица (`--font-body`). Системный стек — только как fallback. Числа Пульса — `font-variant-numeric: tabular-nums` (класс `.nums`, он же переключает на Manrope).

| Токен | Размер/интерлиньяж | Использование |
|---|---|---|
| `display` | 40/44, вес 700 | большие числа Пульса, баланс очков |
| `h1` | 24/30, 700 | заголовки экранов |
| `h2` | 19/24, 600 | заголовки карточек, секций |
| `body` | 16/22, 400 | основной текст (минимум для любого текста) |
| `label` | 14/18, 500 | чипы, кнопки, подписи |
| `caption` | 13/16, 400 | время, метаданные (только `--text-muted`) |

### Форма и пространство

- Радиусы: карточка 16, кнопка/чип 12, FAB и аватар — круг, шторка 20 (верхние углы).
- Сетка отступов: 4/8/12/16/24/32; боковые поля экрана 16.
- Тени: статичные. Карточки — рецепт `card` (`@utility` в globals.css: радиус 16, обводка `--border`, лёгкий градиент поверхности сверху вниз, `--shadow-card` = свет по верхней кромке + мягкая тень); поля — `field` (радиус 12, `--surface-2`, кольцо фокуса акцентом); шторки/FAB — `--shadow-raised`. Кнопки: `btn-primary` (градиент акцента с мягким свечением), `btn-secondary` (приподнятая поверхность), `btn-gold` (награда). Тени НЕ анимируются (перф-контракт) — «подъём» передаётся scale 1.02 + подсветкой обводки.
- Минимальная зона тапа 44×44.

### Ничего системного в полях

Браузер рисует внутри контролов свою фурнитуру — стрелки, счётчики, крестики, уголок растягивания, полосы прокрутки со ступенчатыми стрелками. Она приходит в форме системы, а не в нашей, и в тёмном интерфейсе читается как чужая деталь. Политика: **любой родной элемент управления либо переопределён, либо заменён своим**.

- `field` = `appearance: none`; `textarea.field` не растягивается мышью; у `select` своя шевронка; ▲▼ у числового поля сняты; крестик очистки в поиске — свой (`×` в правом краю поля); автозаполнение Chrome перекрашивается обратно inset-тенью в `--surface-2`; выделение текста — акцентное.
- Полосы прокрутки: тонкий скруглённый ползунок `--text-muted`, без кнопок-стрелок. Там, где контент сам показывает, что он длиннее (лента переписки, шторки, списки в шторках), полосы нет вовсе — утилита `.no-bar`.
- Поле ввода сообщения растёт под текст до пяти строк и только потом скроллит.
- **Дата и время — свои компоненты, `components/ui/datetime`** (арифметика — `lib/datetime/calendar.ts`, покрыта тестами). Календарь: неделя с понедельника, всегда шесть строк (панель не прыгает при смене месяца), сегодня — акцентом с точкой, вне диапазона — гашение. Часы: сетка часов + чипы минут (шаг 15), в узкой колонке сетка сама сужается до четырёх столбцов. Панель раскрывается под полем (не оверлеем — работает внутри шторки) и закрывается тапом мимо. Пара «дата + время» делит одну панель во всю ширину. Значения — по актюбинским настенным часам: день `YYYY-MM-DD`, время `HH:MM`, наружу — ISO с `+05:00`.

### Движение

| Токен | Значение | Использование |
|---|---|---|
| `--t-instant` | 100–150ms, ease-out | микрофидбек: тап, чип, переключатель |
| `--t-screen` | ≤150ms, ease-out | переходы экранов (мгновенность важнее красоты) |
| `--t-effect` | 200–900ms по каталогу | game feel (FRONTEND.md), полная версия только в ключевые моменты |
| `--t-tv` | 400–600ms, ease-in-out | ТВ-режим |
| пружина | stiffness 260, damping 24 | карточки, маскот, счётчики |

Только `transform`/`opacity`/цвет; `prefers-reduced-motion` уважается всюду (маскот замирает в статичной позе состояния).

### Скелетоны и загрузка (без сдвигов)

Система — `components/ui/Skeleton.tsx` (кости-блоки) и `components/ui/PageSkeletons.tsx` (композиции страниц). Правила:

1. **Кость = коробка настоящего элемента.** Каждый блок повторяет размеры реального компонента (высоты, отступы, радиусы): карточка задачи, строка списка, стат-бокс, строка рейтинга, объявление, секция настроек, строка таблицы. Меняется только содержимое, не геометрия.
2. **Одна картинка от тапа до данных.** Композиция страницы используется дважды: в `loading.tsx` маршрута (мгновенно при навигации) и в самой странице, пока идёт запрос. Статичная шапка страницы (заголовок, подзаголовок, фильтры) рендерится сразу и не входит в скелетон.
3. **Область, чья высота неизвестна, меняется одним коммитом** вместе со всем, что ниже неё (Пульс: инбокс + «Люди»). Элемент, появляющийся после монтирования (карточка уведомлений), стоит последним.
4. **Никаких «…», «Загружаю…»** в местах, где потом будет число или список — там кость той же высоты.
5. **Движение только прозрачностью**: `.skeleton` пульсирует opacity, контент появляется через `card-in`/`page-enter` без translate. Переключение фильтров держит прошлые данные (`keepPreviousData`), а не показывает скелетон заново.
6. Критерий: CLS страницы при замедленной сети ≈ 0 (замер — Playwright + PerformanceObserver `layout-shift`).

## 3. Маскот (D-45)

### Концепция

Персонаж-ассистент продукта. Одна простая геометрическая фигура, живущая в двух ролях:
- **Для директора — ассистент**: слушает (во время записи — пульсирует в ритм голоса вокруг FAB), думает (на распознавании), докладывает («Понял так: …»). Только нейтрально-рабочие состояния. Появляется с MVP.
- **Для сотрудника — эмоциональный телеграф директора**: постоянный маленький индикатор в шапке личного канала, передающий отношение директора к текущему положению дел этого сотрудника. Включается по гейту адаптации.

### Пять состояний телеграфа

| Состояние | Триггеры (факты, не настроение) | Форма | Цвет | Пульс | Угасание |
|---|---|---|---|---|---|
| Доволен | done в срок/досрочно, 🔥/похвала, +очки | мягкая, чуть раздутая, медленное дыхание и редкие искры (без подпрыгивания — владелец, 2026-09-16) | `--gold` | медленный, глубокий | → спокоен за 24ч |
| Спокоен | базовое состояние | ровный круг/капля | `--accent` | «дыхание» 6с | — |
| Ждёт | задача принята, дедлайн приближается; неотвеченный вопрос директора | слегка вытянута вверх, «смотрит» | `--warn` 60% | умеренный | → спокоен при действии |
| Встревожен | дедлайн < 24ч; директор открывал задачу без реакции | сжата на 8%, частота выше | `--warn` | учащённый, мелкий | → спокоен/недоволен по исходу |
| Недоволен | просрочка, rework, 👎, revoked из-за бездействия | сжата и заострена книзу, почти замер | `--danger` 70%, приглушён | редкий, «тяжёлый» | → спокоен за 48ч или при закрытии долга |

Правила поверх таблицы (из D-45, обязательны): негативные состояния видит ТОЛЬКО адресат в своём канале — никогда в Эфире, рейтинге, на ТВ; тон строгий, не карикатурный (никаких «злых бровей» — только форма/цвет/ритм); при показе штрафа маскот НЕЙТРАЛЕН (сухой UI, телеграф не злорадствует); телеграф отключаем в `company.settings.mascot_telegraph`; настроение пересчитывается из фактов и угасает — не «прилипает».

### Роль ассистента: хореография по этапам (владелец, 2026-09-11)

Одна фигура, но на каждый этап конвейера — своя узнаваемая сцена (`components/brand/Mascot.tsx`, ключевые кадры в `app/globals.css`; поза на входе одноразовая, тело — цикл, глаза — пара, реквизит — вокруг фигуры):

| Состояние | Поза / тело | Глаза | Реквизит |
|---|---|---|---|
| `listening` | наклоняется к голосу (−9°), кивает в такт; громче голос — глубже кивок и шире фигура | широкие, смотрят к уху, лёгкий прищур внимания | справа вырастает ухо (с раковиной), изредка вздрагивает; звуковые дуги входят в ухо |
| `saving` | принимает записку: сжатие и оседание | полуприкрыты, провожают записку вниз | записка опускается сверху в голову и исчезает |
| `transcribing` | наклон «читаю через плечо», спокойное дыхание | бегут по строке слева направо и возвращаются | слева полоски голоса гаснут, справа печатаются три строки текста |
| `parsing` | размышление (наклон) | смотрят вверх на карточки, затем вправо | карточки появляются над головой по одной и уходят в стопку вправо |
| `sending` | замах назад, бросок вперёд со сжатием, возврат | провожают карточку вверх-вправо | карточка живёт в самом лице (`mascot-throw-card`): появляется в руке на замахе, улетает вверх-вправо ровно в момент броска и гаснет. | `offering` | вжимается и отскакивает, как кнопка под пальцем (цикл 1,6 с) | едут за телом с задержкой | из тела расходится кольцо-рябь, над головой стопка разобранных карточек подпрыгивает на отскоке — лицо само просит тап (D-60, шестое уточнение; словами «тапни меня» не пишем) |
| `speaking` | лёгкие кивки | обычные | рот открывается в ритме фразы (D-49) |
| `thinking` | наклон, пауза | бегают | три точки над головой |
| `sleeping` | самое медленное дыхание (8 с), приглушённый цвет | закрыты | два «z» уплывают вверх (и больше ничего над головой); Пульс до первого тапа |
| `alert` | выпрямляется на входе и замирает, поверхностное дыхание, раз за цикл прислушивается поворотом | медленно ведут по сторонам и задерживаются на краях | маленькое ушко встаёт на макушке и подёргивается в такт повороту, цвет `--warn` (D-70) |
| `calling` | наклон к зрителю на входе, два настойчивых подскока с креном, пауза | широко раскрыты, смотрят на человека | «!» выскакивает над головой на каждом подскоке, цвет `--warn` (D-69) |
| `surprised` | вздрагивание на входе (550 мс), дыхание 3,2 с | широкие, смотрят вверх на облачко | маленький круглый рот; облачко мысли над головой (Пульс: событие на доске) |
| `processing` | подключение к хранилищу, три такта чтения, фиксация, затем приседание и прыжок | глаза заменяются глифами `0 1 { } < >` (рывком, как терминал), взгляд идёт по строке; на фиксации замирают | слева цилиндр БД и биты данных в голову; в верхней точке прыжка — галочка нового статуса (D-65) |

| `panicking` | трясёт целиком (0,48 с), поза вжата | широко раскрыты | две капли пота в разном ритме, цвет `--danger` |
| `checking` | шарик «Задачи» (D-82): наклон к планшету, кивок на каждую галочку, довольный подъём в конце | идут по строкам вниз, в конце — на директора | планшет в руках, галочки встают в строки по очереди; реквизит в цвете шарика |
| `chatting` | шарик «Сообщения»: повернулся к собеседнику, потом отвечает мелкими кивками | налево вверх на входящий пузырь, затем направо на свой | слева пузырь с «печатающими» точками (`--warn`), справа ответ, строки печатаются, рот шевелится |
| `announcing` | шарик «Эфир»: выпрямляется; вдох с откидыванием, выкрик с толчком вперёд (1,4 с) | чуть вправо-вверх, по ходу голоса | мегафон у рта (`--gold`), из раструба расходятся дуги, рот круглый на выкрике |
| `scheduling` | шарик «Календарь»: поворот к календарю над плечом, вздрагивает на отрыве листа, кивок «записал» | на календарь, вниз за падающим листом, обратно | отрывной календарь: верхний лист отрывается и падает, сегодняшний день обведён и пульсирует |
| `serving` | просьба секретарю (стол справа, D-86): поклон на входе, осторожное покачивание | мягкий прищур, то на чашку, то на директора | чашка на блюдце с паром (`--gold`), улыбка и румянец |
| `celebrating` | пачка долетела (1,8 с после броска): настоящий прыжок, тень отрывается от земли | счастливый прищур, улыбка, румянец | конфетти с макушки; цвет `--gold`. При ошибке отправки не играет |

**Сценки в покое (D-82).** Поверх состояния лицо само играет короткие сценки (`act`, `components/pulse/useMascotActs.ts`): каждые 6–12 с одну из подходящих, без повтора подряд, и возвращается в состояние без шва. Спящее спит дальше — зевок, храп пузырём, переворачивается, клюёт носом (глаза на миг приоткрываются), бормочет пузырём с точками, улыбается во сне, «бежит» во сне с пылью. Бодрствующее на кольце шариков ждёт выбора — машет рукой, подмигивает, подпрыгивает, кружится (тело ребром), насвистывает нотами, отпускает сердечко, следит взглядом за шариками, зевает. Настороженное только выглядывает по сторонам и тянется на цыпочках — других чувств у директорского лица нет (D-70). Две сценки экран вызывает сам: **пробуждение по тапу — привет рукой, засыпание по тапу — зевок** (если нет тревоги). Пока идёт конвейер, открыт шарик, висит ответ или мысль — сценок нет; при `prefers-reduced-motion` — тоже.

**Палитра сотрудника (D-69, D-70).** Лицо в Ленте чувствует за того, кто работу несёт: непринятое поручение (`sent`) или возвращённое на доработку (`rework`) — **зовёт** (`calling`), свой срок в пределах часа или просрочка — `panicking`, непрочитанное слово директора — `nervous`. Зов важнее прочего: пока не принял, лицо зовёт — и в покое, до первого тапа, тоже: наклоняется к человеку, дважды подскакивает с креном, над головой выскакивает «!». Состояние держится, пока человек не нажал «Принял» (или не забрал доработку в работу), и не путается с тревогой директора: у сотрудника это единственное настойчивое состояние, всё остальное — прежние «спокоен» и «доволен».

**Барометр доски (D-68, уточнён D-70).** Лицо на Пульсе показывает не только событие, но и **положение дел**. Тревог по-прежнему три и вес тот же — срок (в пределах часа или уже прошёл) → поручение висит непринятым полчаса → непрочитанное слово сотрудника, — но **у директора все три дают одно лицо: `alert`, «насторожен»**. Негативных состояний у директорского ассистента нет вовсе (D-70): злость, паника и нервы живут на стороне сотрудника, который эту работу несёт. Что именно ждёт директора, говорят шарики и строка ассистента; ниже тревоги — прежние «спокоен» и «доволен». Правило рассчитывается чистой функцией `lib/pulse/mood.ts` из тех же строк доски и тех же часов. Мысль о событии (`processing`, D-65) и речь ассистента перебивают настроение на своё время. **Лицо в покое спит только тогда, когда всё спокойно** (владелец, 2026-09-17: «маскот должен меняться не только когда на него нажимают, а и в состоянии покоя»): есть настроение — оно и показывается вместо сна, и сны D-67 в это время не летают. Это **своя** реакция ассистента для глаз директора; запрет D-45 на карикатурность касается телеграфа сотруднику и остаётся в силе.

**Экран ожидания (D-68, D-69, владелец, 2026-09-17).** Пока домашний экран в покое, он не пустая панель, а сцена. Слои снизу вверх: **команда** → **сон** → лицо; всё, кроме лица и кружков людей, не берёт тапов, и при первом касании сцена гаснет за 180 мс. Условие — покой экрана (`mode === "idle"`, пуст конвейер, нет мысли), а не поза лица: после D-70 лицо в покое барометр и спит не всегда.

- **Команда (только у директора), D-71.** Две половины, лицо между ними. **Сверху** — все, у кого есть работа, звёздами с лучами: крупнее — больше на человеке, имён нет, верх это объём работы в воздухе. **Цвет звезды — стадия задачи директора** (D-73): сверхновая — выдана и ещё не принята, жёлтая — принята и делается, зелёная — сдана и ждёт приёмки, красная — вопрос, «не могу» или просрочка; человек носит самую громкую из своих. Лучи дышат не в такт ядру — этим звезда и мерцает. **Тап по звезде** поднимает мини-карточку: имя и до трёх его задач со стадиями, только чтение, ни одной кнопки. **Снизу** — бездельники, кружками с инициалами: стоят **рядами** и мелко дрожат (рядов столько, сколько влезает по высоте). **Первый ряд начинается ниже слов под лицом** (владелец, 2026-09-18): пока открыт микрофон, под головой висит «Слушаю… 0:07» и «веди вверх, чтобы отменить», и ряд стоял ровно на них. Взамен пол получил право занимать нижний отступ, который полёт обязан оставлять пустым, — иначе на коротком экране (SE) это стоило бы целого ряда людей. **Тап по кружку выбирает человека** (D-84): лицо просыпается и **смотрит на него** — глаза уходят в его сторону, голова чуть наклоняется, от кромки головы к кружку тянется пунктир взгляда; кружок в акцентном кольце, остальные притухают. Над головой выезжает карточка с хвостиком к лицу: имя, «Записать» (тап — запись, «Готово»), «Текстом», «или зажмите маскота и говорите»; удержание лица пишет задачу для выбранного, тап по лицу — тоже запись. Имя приклеивается к началу расшифровки, а сам человек уходит в парсер по id — говорить можно только саму задачу, тёзки не путаются, конвейер остаётся один. Как только задача падает, его кружок **ныряет в лицо** и вылетает сверху звездой — 1,7 с в три акта (D-74): замах и разгон с растяжением вдоль пути, заглатывание на кромке головы; кольца на кромке, пока маскот обрабатывает; резкий вылет с перелётом за точку и ударной волной. Закрылась последняя задача — звезда спокойно опускается назад, одним движением: с ним ничего не случилось, просто кончилось. Место человека в каждой половине — хеш от него, а не от порядка в списке, поэтому он не переезжает, когда меняются соседи. Потолки: 28 звёзд и 12 кружков (это что рисуется, а не что правда). Сданное на приёмку — всё ещё звезда. Сотруднику чужие состояния не показываются (D-45).
- **Стол секретаря (D-86).** Секретари — не кружки и не звёзды: справа от лица, на уровне его подбородка, стоит стол с маленьким маскотом того же персонажа в глубоком бирюзовом (`--accent-2`). Пока никто не просит — он печатает: тело покачивается в ритме клавиш, на мониторе печатаются и гаснут строки, мигает курсор, над кружкой поднимается пар; на мониторе значок числа живых заявок. Тап — он подпрыгивает и поворачивается к лицу, лицо поворачивается к нему и приносит чашку, и через треть секунды над головой выезжает карточка с клавишами заявок — пилюлями по ширине надписи, рядами, как клавиатура; если над лицом не хватает высоты, карточка опускается на лицо, а не прячет ряд за прокруткой (D-87). Всё — transform/opacity; движение стола замирает, пока секретарь смотрит на директора.
- **Маскот секретаря (D-87).** В Ленте роли `secretary` лицо — не «Капля», а `SecretaryMascot` (`components/secretary/`): та же капля в бирюзовом секретаря (`--accent-2`), гарнитура с дужкой и микрофоном, бабочка, блики в глазах. Сцена — по главной просьбе директора (`lib/errands/scene.ts`): **покой** — печатает за ноутбуком, изредка смотрит вверх; **просят** — огонёк гарнитуры мигает `--warn`, дуги звонка от уха, подскоки `mascot-call`, над головой облачко с картинкой просьбы (чашка, чайник, знак «нет входа», дверь с гостем); **в работе** — кофемашина слева (палец на кнопке, струя, чашка наполняется, пар), чайник над чашкой с ярлычком пакетика, табличка «нет входа» в руке + палец у губ + «тсс», дверь открывается и гость входит под поклон, звонок врачу, шаги к директору с блокнотом, блокнот с ручкой для своей кнопки; **готово** — прищур, улыбка, румянец, галочка `--ok` (1,8 с). Под лицом — строка «что делаю», под ней карточки заявок. Ключевые кадры `smc-*` — `components/secretary/secretary-mascot.css`; только transform/opacity. Все сцены на одном экране — `/dev/secretary`.
- **Маскот секретаря, D-97.** Покой — за столом: окно по времени суток компании (утро/день/вечер, ночью — луна и секретарь дремлет, «z», монитор погас), часы на стене, цветок, кружка с паром, бумаги, монитор с печатью, руки на клавиатуре; раз в 20–40 с сценка (глоток, гарнитура, потянуться, взгляд на часы, бумаги, полить цветок; утром — приход с сумкой). Просят — срочность в три ступени (подскоки → чаще и облачко трясётся → бег на месте, `--danger`), «+N» на облачке. «Принял» — кивок и галочка у гарнитуры. «Готово» — развязка сцены 2,2 с (унёс чашку, закрыл дверь, убрал табличку, машина уехала) и галочка. Новые сцены: вода, машина, печать, обед, курьер, переговорная. «Не беспокоить» — лампа вверху экрана и притушенные края. Стол директора: маленький секретарь того же вида держит работу, на мониторе — картинка просьбы, после «Готово» подносит чашку лицу. После гейта (D-40): конфетти за быстрое «Готово», сердечки за «спасибо». Все сцены — `/dev/secretary`.
- **Сон (D-67).** Из середины головы вылетает капля, за ней преследователь: ракета, китайский дракон, монстр; с D-82 ещё бумажный самолётик с пунктиром маршрута (летит один), рой из четырёх пчёл и НЛО с бегущими огнями и кольцом-лучом — шесть снов по кругу. Первый сон через 2,6 с, полёт 14 с, между снами 5 с. Погоня держит дистанцию (D-77): преследователь целится в точку ~195 px позади беглеца и тормозит при сближении, иначе он едет у беглеца на спине и капли не видно (медиана разрыва 27 → 127 px).
- **Движение сна** — управляемый полёт с инерцией: предел скорости поворота, постоянный снос с курса, непрерывное отталкивание от краёв (у края фигура уходит дугой) и погоня на упреждение. Симулируется один раз на старте сна и пишется в keyframes под измеренный экран — после старта JS спит (`lib/idle/flight.ts`).
- **Сон задевает команду (D-77).** Прошёл рядом со звездой — звезда вспыхивает; рядом с бездельником — кружок приседает и отлетает по нормали к полёту; над головой — по кромке лица расходится волна. Тело дракона гнёт ряд по очереди, звено за звеном. Считается вместе с полётом (`lib/idle/wake.ts`): на каждого задетого пишется одна анимация на весь сон с горбом в момент касания — JS по-прежнему спит. Реакция трогает только форму, положение и яркость: цвет — это стадия задачи (D-73), а выражение лица — телеграф дня директора (D-45), и сон не пишет ни туда, ни туда.
- **Бюджет** (замер при дросселировании CPU ×4): семь человек и сон — медиана кадра 6 мс, p95 12 мс; компания из 59 (28 звёзд + 12 кружков) — медиана 12 мс, p95 48 мс. Реакции на сон (D-77) сверху ничего не стоят: на `/pulse` с ними и без них медиана одна и та же (6,1 мс, кадров тяжелее 32 мс — ноль), на полке с компанией из 52 разница тонет в разбросе между прогонами. При `prefers-reduced-motion` сцены нет вовсе.

Правила прежние: только transform/opacity, один SVG, `prefers-reduced-motion` замораживает позу. Полка анимаций — `/lab/mascot` (все состояния, жесты над лицом и сцены оверлея под общими ручками: размер, фон, пауза, переигрывание, уровень голоса).

### Геометрия и реализация

- **Форма утверждена (D-45, 2026-08-18): «Капля»** — мягкий блоб с двумя глазами-точками (моргание раз в ~4–5 с; в «доволен» — прищур-улыбка, в «недоволен» — полуприкрыты, без бровей и рта). Проба и отвергнутые кандидаты («Кольцо», «Искра») — `archive/design-probes/mascot-proba.html`. Малые размеры (≤28px, телеграф в шапке): глаза укрупняются пропорционально (~12% фигуры) либо упрощаются до одной точки — проверять читаемость на Redmi-классе.
- Компонент `<Mascot state size />`: один SVG (все позы — слои с crossfade opacity) ЛИБО canvas; переходы состояний — пружиной по scale/skew/translate.
- Перф-контракт (D-45): анимируются только transform/opacity/цвет; запрещены анимируемые `filter`/`box-shadow` (свечение = пре-рендер слой + opacity); покойное дыхание — чистая CSS-анимация (JS спит); полная пауза вне вьюпорта, при свёрнутой вкладке и `prefers-reduced-motion`; суммарный вес ≤5 КБ; бюджет <2 мс/кадр на Redmi-классе.
- Хаптик сопровождает смену состояния только на Android и только на переходах вниз/вверх (не на дыхании).

## 4. Жесты (D-60)

Телефон — основной экран продукта, поэтому у директора главный орган управления не кнопка, а **маскот в центре**, и большая часть действий делается пальцем, не тапом по мелкому контролу. Жесты — ускорители: у каждого есть видимый запасной путь (кнопка на карточке, чип, ссылка), иначе его нельзя угадать.

| Жест | Где | Что происходит |
|---|---|---|
| Удержание (≥250 мс) | маскот | дрожь 220 мс + хаптик, состояние «слушает» **на самом маскоте экрана** (оверлей не открывается, D-60 пятое уточнение): лицо раздувается по громкости, за ним акцентная заливка (других колец у лица нет), под ним подпись «Слушаю… 0:07» и «веди вверх — отмена»; отпустил — то же лицо играет «Сохраняю → Распознаю → Разбираю → Отправляю»; ведёшь вверх ≥60 px — отмена |
| Тап | спящий маскот | просыпается (потягивание 520 мс), говорит сводку, и вокруг него начинают **кружить три шарика**: «Задачи» (число задач, требующих директора: просрочки, отказы, приёмка; цвет худшей дорожки), «Сообщения» (открытые вопросы сотрудников, жёлтый), «Эфир» (объявления, золотой); орбита 28 с, подписи не вращаются; второй тап — шарики уходят, маскот засыпает |
| Тап | шарик | панель под рядом шариков: «Задачи» и «Сообщения» — стопка карточек с жестами (в «Сообщениях» без карточки «В работе»), «Эфир» — объявления с «Ознакомились»; маскот уменьшается и уходит вверх, шарики встают в ряд; тап по активному шарику складывает панель, шарики снова кружат |
| Потянуть вниз (≥44 px) | маскот | поле текста с клавиатурой |
| Свайп влево / вправо (≥56 px или флик) | верхняя карточка стопки | следующая / предыдущая; порядок D-05; подсвечивается её шарик |
| Свайп вверх (≥88 px) | карточка | главное действие дорожки: приёмка — «Принято», отказ — «Настоять»; тост «… · Отменить» 4 с, вызов уходит после; просрочка и вопрос — открывается полная карточка (там выбор) |
| Свайп вниз (≥88 px) | карточка | отложить: карточка уходит в конец стопки до следующего открытия |
| Тап | карточка | полная карточка со всеми кнопками директора в шторке |
| Долгое нажатие (480 мс без движения) | карточка | меню: открыть, переназначить, отозвать, удалить |

Правила:
- **Открытие — спящий маскот** в середине экрана (владелец, 2026-09-16, вечер): глаза закрыты, медленное дыхание, «z» над головой; ни сводки, ни карточек, ни подсказок под ним. Тап будит его. Обзор дают три шарика с числами. Эфир по тапу не открывается — он один из шариков.
- **События — мысли** (владелец, 2026-09-16, ночь): изменение на доске («Марат: задача «…» сдана») показывается **облачком мысли над головой** (`ThoughtBubble`, хвост из двух кружков к голове), маскот при этом просыпается и смотрит на облачко с лёгким удивлением (`surprised`); через 9 с мысль тает и он засыпает снова (если экран был в покое); тап по облачку убирает мысль раньше. Сводка по тапу — речь, строкой под лицом, с движением рта; мысли под лицом не показываются. Подсказка жестов — в самом низу экрана, над таб-баром; служебные строки (push, черновик, пустая команда) появляются под строкой ассистента только после тапа.
- **Стопка** появляется только из шарика; последняя карточка — «В работе · N» со ссылкой на «Задачи». Ширина экрана раскладку не меняет: широкое окно центрирует тот же экран (владелец, 2026-09-17).
- **Отмена.** Действие по свайпу показывается сразу, на сервер уходит через 4 с; тост с «Отменить» возвращает карточку. Матрица статусов обратного хода не имеет, поэтому отмена — задержка, а не откат.
- **Браузер не мешает.** У маскота и верхней карточки `touch-action: none`, `user-select: none`, `-webkit-touch-callout: none`, контекстное меню подавлено; у экрана `overscroll-behavior-y: contain` (нет pull-to-refresh); горизонтальный свайп начинается с центра карточки, край экрана остаётся системе (iOS «назад»).
- **Подсказка.** Внизу экрана строка «удержи — говори · тап — задачи · потяни вниз — текст» первые пять голосовых, затем исчезает.
- **Перф.** В DOM три карточки (предыдущая, верхняя, следующая); анимации только transform/opacity; пружина 260/24; `prefers-reduced-motion` уважается через `MotionConfig`.
- Сотрудник и ТВ — той же грамматикой во второй очереди: удержание маленького маскота в шапке Ленты для голосового отчёта, свайп по делу как ускоритель кнопок (три кнопки остаются, принцип 2), стопка как фокус-режим на ТВ.

## 5. Tone of voice

Все системные тексты — голос ассистента, первое лицо, коротко, по-деловому, без канцелярита и без восклицаний в негативе. Ассистент говорит «я» о своих действиях и называет факты — никогда оценок личности.

| Событие | Текст (эталон) | Анти-пример |
|---|---|---|
| Распознано голосовое | «Понял так: 3 задачи и объявление» | «Ваш запрос успешно обработан!» |
| Отправка задач | «Отправил Марату и Ерлану» | «Задачи были созданы» |
| Квитанция доставки | «Марат не открывал с 9:14» | «Марат не получил / игнорирует» |
| Push новой задачи | «Новая задача до 18:00: КП для Казхрома» | «Внимание!!! Срочное поручение» |
| Принятие | «Принял. Отчёт можно текстом, фото или голосом» | «Статус изменён на accepted» |
| Начисление | «🔥 +10 от директора — за скорость» | «Вам начислено 10 баллов» |
| Штраф | «−5: просрочен дедлайн по „КП Казхром“» (нейтрально, без эмодзи) | «Увы! Вы оштрафованы :(» |
| Возврат на доработку | «Директор вернул задачу. Голосовой комментарий внутри» | «Задача отклонена» |
| Пустая лента задач | «Пока тихо. Появится задача — разбужу» | «Здесь ничего нет» |
| Оффлайн-очередь | «Отправлю, как появится связь (2 в очереди)» | «Ошибка сети» |
| Ошибка STT | «Не расслышал. Аудио сохранил — повторить?» | «Ошибка транскрипции аудио» |

Правила: похвала — тепло и с эмодзи; штрафы и просрочки — сухие факты, без эмодзи и восклицаний; время всегда конкретное («с 9:14», «до 18:00»); имена — как в ростере; русский язык, «ты» сотруднику не используется — нейтральное обращение без местоимений, к директору — тоже без местоимений.

## 6. Клиентская кастомизация (граница)

Разрешено через `company.settings.brand`: `logo_url` (шапка, экран входа), `accent` (с проверкой контраста, см. §2). Запрещено и не реализуется: смена палитры целиком, шрифтов, радиусов, замена/скрытие маскота (телеграф можно отключить функционально — D-45, но персонаж остаётся в ассистентских ролях), любые «если клиент X» в коде (V-02).

## Открыто

- Финальный hex `--accent` и форма маскота (A/B/C) — по итогам визуальной пробы, пакетом с именем продукта и именем персонажа (D-20).
- Светлая тема — не раньше этапа масштаба, по запросу клиентов.
