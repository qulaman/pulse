## Задача 3 — трекер «план/факт» (`tracker/index.html`) — главная задача

Одностраничный HTML-дашборд разработки. Требования:

**Технические:**
- Один файл, ноль внешних зависимостей (никаких CDN, шрифтов по сети) — открывается с `file://` и офлайн.
- Все данные — в ОДНОМ `<script>`-блоке `const DATA = {...}` в начале файла, с комментарием-инструкцией как обновлять. Рендер — ванильный JS из этого объекта. Это позволит и человеку, и агенту обновлять факт одной правкой JSON.
- Мобильный и десктопный вид (дашборд будут смотреть с телефона).
- Если доступен скилл `frontend-design` — используй его перед вёрсткой.

**Дизайн:** тёмная тема в духе продукта (фон `#0B0F14`, карточки `#131A22`, статусные green/yellow/red только для состояний, один акцентный цвет). Крупная типографика ключевых чисел. Строгий, дорогой вид — без визуального шума.

**Структура данных и разделы страницы:**

1. **Шапка-сводка**: название проекта, текущая неделя (вычислять от `DATA.startDate` — пока поставь `null` и выведи «старт не назначен»), прогресс-бар «N из M задач», счётчики по статусам.
2. **12 недель** — сетка/лента карточек недель из `PLAN_12_WEEKS.md`. Каждая неделя: номер, название, список задач с чекбоксами-статусами (`plan | in_progress | done | dropped`), «✅ критерий недели» (текст), поле факта (`factNote` — что реально вышло, дата закрытия). Статус недели вычисляется из задач. Перенеси ВСЕ недели и их пункты из `PLAN_12_WEEKS.md` добросовестно, ничего не выдумывая и не сокращая смысл.
3. **Метрики пилота** — карточки с целями и фактом (факт пока `null` → прочерк): % поручений через систему (цель >80%), доля правок на подтверждении, % сотрудников с ≥1 задачей (цель >70%), push-доставляемость, голосовое→карточка < 3 сек, холодный старт < 2 сек.
4. **Журнал пятничных демо** — таблица/список: дата, неделя, что показали, реакция директора. Пока пусто, но структура и пример-заглушка в комментарии.
5. **Вехи Б-трека** (ТОО, Astana Hub, транши, закуп мерча) — отдельный компактный блок, статусы те же.

**Косметика:** заголовок вкладки «WAG Pulse — Трекер», favicon-эмодзи через data-URI не нужен, `lang="ru"`.

Коммит: `feat(tracker): plan/fact dashboard v1`.
