# WORKLOG — журнал работы над WAG Pulse

Общий журнал для всех окон/агентов. Каждый агент в конце сессии дописывает запись СНИЗУ (append-only, старые записи не редактировать). Формат:

```
## [дата] — [окно/агент] — [короткий заголовок]
- Сделано: ...
- Коммиты: ...
- Решения/находки: ...
- Дальше: ...
```

## Правила координации окон

| Зона | Владелец |
|---|---|
| Продуктовые решения, `DECISIONS.md`, содержание `docs/*.md`, `/tasks/*.md` | Окно 1 (исследование, с владельцем проекта) |
| git, структура папок, `tracker/index.html`, правки путей в `CLAUDE.md` | Окно 2 (параллельный агент, `AGENT_TASK.md`) |
| `/reviews/*` — экспертное ревью концепта командой из 5 специалистов | Окно 3 (тимлид-оркестратор, `AGENT_TEAM_REVIEW.md`) |
| `WORKLOG.md` | Общий, только append |

Вопросы, требующие продуктового решения, агенты НЕ решают сами — пишут в «Открытые вопросы» ниже.
