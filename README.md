# Pulse

> Рабочее название (финальное имя — D-20). Первый клиент и пилотная компания — West Arlan Group (WAG).

**SaaS-продукт «голосовое управление компанией»** (видение V-01): директор голосом раздаёт поручения, объявления и бонусные очки → AI превращает речь в структурированные карточки → сотрудники получают их на телефоны, отчитываются и соревнуются → директор видит всю компанию в реальном времени. Продукт — личный ассистент директора + геймификация работы для сотрудников. Клиент №1 и полигон — West Arlan Group (Казахстан); модель поставки — изолированный инстанс на клиента (V-02).

**Текущий этап:** ядро и модули построены, описание продукта ведётся параллельно. Календарного плана реализации нет намеренно (D-46).
