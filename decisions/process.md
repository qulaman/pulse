### D-188. «Уменьшить движение» системы приложение не слушает: анимации играют у всех · ✅ действует
**Решение.** Владелец (2026-11-23): «я вообще не знал что есть функция уменьшить движение. его вообще нужно убрать». Настройку системы `prefers-reduced-motion` (iOS «Уменьшить движение», Android «Убрать анимацию», Windows «Показывать анимацию») приложение не читает: движение, переходы, сценки и сон маскота — у всех одинаково.
- из CSS убраны блоки `@media (prefers-reduced-motion: reduce)`, из кода — `useReducedMotion`, `matchMedia(…reduce…)` и `MotionConfig reducedMotion="user"`; режим `REDUCED=1` смоука маскота убран
- пункты о `prefers-reduced-motion` в прежних решениях (D-110, D-118, D-119, D-143, D-151 и др.) больше не действуют
**Цена.** У людей, которые выключили анимацию во всей системе, наши анимации всё равно играют.
**В коде.** Нигде — проверка: `git grep -n "prefers-reduced-motion\|useReducedMotion"` пуст.
**Связи.** Принцип 1a (game feel обязателен); движение — D-131, D-166.

### D-202. Реестр решений — по файлам областей; запись не длиннее 1500 знаков · ✅ действует
**Решение.** `DECISIONS.md` — только голова: «Сейчас действует», «Ждёт владельца» и указатель; сами решения лежат в `decisions/<область>.md`, одно решение — одна запись. Агент читает голову и файл своей области, а не весь реестр.
- запись — не длиннее 1500 знаков (строка «Виза» не в счёт): что решено, правила с числами и правами, чего не делаем, главные места в коде; как ведёт себя экран, описывает документ области — запись ссылается на него строкой «Подробно»
- вопрос владельцу — строка «Виза» в записи; список «Визы», указатель областей и следующий свободный номер в `DECISIONS.md` собирает `pnpm decisions:index`, руками их не правят
- тест падает, если голова не пересобрана, запись длиннее предела, номер повторяется или у записи «ждёт визы» нет строки «Виза»
- номер, на который код ссылается раньше записи, занимают строкой «D-NNN занят …» в «Нумерации» головы — следующий свободный считается и по ним
- номера решений не меняются; полный текст записей до сжатия — `archive/decisions/DECISIONS-2026-11-26.md`
**В коде.** `scripts/decisions-index.ts`, `tests/decisions-index.test.ts`, `decisions/`.
**Связи.** Уточняет D-161 (один файл — голова и области); образец — указатель схемы D-162.
